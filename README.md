# MDXQ2026_SIGNATE_Theme3_exercise03_calc_Score

マナビDXQuest2026 Theme3 演習03 スコア計算ツール

Streamlit を用いた機械学習二値分類の評価指標（ROC-AUC, PR-AUC, Log Loss など）計算Webアプリケーションです。
6000件（1000人×6期間分など）のデータを対象に、**「全期間まとめ」** と **「各期間ごと」** の両方でスコア算出・比較・可視化が行えます。

## CSVデータ仕様

- **正解データ CSV**:
  - 先頭行がタイトル行（ヘッダーあり）
  - 1列目: `ID` 列
  - 2列目: `y` 列（正解ラベル: 0 または 1）
- **投稿データ CSV**:
  - タイトル行なし（ヘッダーなし / SIGNATE提出形式）
  - 1列目: `ID` 列
  - 2列目: `予測確率` 列（0.0 〜 1.0）

## 主な機能

- **全期間 & 期間別の評価指標一覧**:
  - 1期間あたり1000件で固定し、自動的に期間1〜6（1000件×6期間）に分割
  - 全期間・各単独期間に加え、「期間1+期間2」から「期間1+期間2+期間3+期間4+期間5」までの累積期間も一覧表で比較
  - 各区分の **件数**, **陽性数 (陽性率)**, **ROC-AUC**, **PR-AUC**, **Log Loss** を表示
- **期間推移グラフ**:
  - 各単独期間における ROC-AUC / PR-AUC / Log Loss の推移を折れ線グラフで視覚化
- **期間切り替え詳細分析**:
  - 「全期間」、各単独期間、または期間1からの累積期間（期間1+期間2〜期間1+期間2+期間3+期間4+期間5）を選択して、以下の分析を深掘り可能
    - 閾値調整スライダー（Accuracy, TPR, FPR, Precision, Recall, F1-Score）
    - 各指標を最大化（FPRは最小化）する**最適閾値へのワンクリックジャンプボタン**
    - ROC曲線 & PR曲線（インタラクティブPlotly）
    - 混同行列（Confusion Matrix）
    - 正解ラベル別の予測確率分布ヒストグラム
    - 誤判定データの抽出プレビュー
- **ダウンロード**:
  - 期間列（`period`）が付与された全期間の結合評価結果CSVをダウンロード可能
